# Kali Linux Portfolio

Personal portfolio website styled as a full Linux desktop — projects, certifications, experience, and an AI assistant that answers questions about me, all inside an interactive OS-like interface.

*Live site:* https://blackpanda999.github.io/kalilinuxportfolio/

## Tech stack

* TanStack Start + React + TypeScript
* Tailwind CSS + shadcn/ui components
* Supabase integration
* Vite build, deployed on GitHub Pages

## Run locally

```sh
npm i
npm run dev
```

## Build & deploy

Pushes to `main` are built and published to GitHub Pages automatically via GitHub Actions.
